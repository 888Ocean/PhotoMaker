# Photo Maker

本地优先的摄影图文创作工作台。第一版围绕素材、选片、图文编排、风格配方、版本和发布档案实现完整流程。

## 启动

需要 Python 3.9 或更新版本，无需安装第三方依赖：

```sh
python3 app.py
```

访问 http://127.0.0.1:4317 。可用 `python3 app.py --port 4318` 更改端口。

## 已实现

- 作品库：创建、搜索、状态筛选、复制、收纳。
- 素材：JPG/PNG/WebP 导入，原片保存，SHA-256 完全重复去重，预览、尺寸、亮度、对比度、边缘强度和主色采样；鼠标拖动或按钮排序；选片和叙事角色。
- 图文：封面、照片顺序、标题、正文与创作备注，编辑自动保存。
- 版本：手动快照、任务前快照、恢复前快照；查看历史；恢复不删除后续导入的原片。
- 风格库：视觉说明、正负提示词、ComfyUI API 工作流；复用配方创建作品。
- 导出：ZIP 包包含顺序选片、全部原始素材、文案、项目版本与来源信息；不自动裁切或调色。
- 发布归档：手工登记发布链接、平台和反馈，绑定发布时版本；不自动发布或读取平台数据。
- 发布目标：小红书、抖音、微博。抖音和微博仅导出素材包，账号接入尚未实现。旧项目移除的目标保留在 `legacy_platforms`，历史发布记录和版本不删除。
- 小红书浏览器辅助（实验版）：官方窗口手动登录、本机会话复用、登录状态检测、选片上传与草稿填写；由用户在官方窗口亲自提交。不会自动发布或把草稿标成发布成功。
- 任务记录：持久化进度、失败原因、来源、模型/工作流信息；服务重启后未完成任务标记失败。
- 示例：显式点击“体验海边示例”使用当前目录原有 `design_output` 中的设计图，原文件不改动。

## AI 接入与边界

在“连接设置”填写兼容 Chat Completions 的服务基础地址（如 `http://127.0.0.1:8000/v1`）、模型 ID 和可选凭证。支持你自选的本地或远程服务。未配置时只提供明确标注的本地规则草案，不伪装成 AI 生成。

一次 AI 任务会真实执行：总监读取项目 → 并行调用选片师、艺术指导 → 图文编辑生成文案 → 校验结构与照片 ID → 统一保存配方和版本。任务期间如果项目发生变化，AI 结果不会覆盖你的编辑。专家目前使用同一已配置模型，通过独立任务上下文分工。

这里的“总监”当前由程序负责调度与校验，AI 部分是固定的三角色模型调用流程，尚不是能自主选择工具、循环决策的 Agent harness。没有接入 Codex 运行时、MCP 或从开源项目提取的 SKILL.md；照片工具是本项目的确定性函数。

“启用图像理解”需模型支持 `image_url` 输入。开启后最多发送前 12 张、最长边 640 像素的预览；关闭时仅发送文件名和指标，不能据此声称理解画面。现在没有人脸识别、语义聚类、相似照片识别、审美评分或本地视觉模型。边缘强度不是可靠的照片清晰度评分。

环境变量也可配置：`PHOTOMAKER_AI_BASE_URL`、`PHOTOMAKER_AI_MODEL`、`PHOTOMAKER_AI_API_KEY`、`PHOTOMAKER_COMFY_URL`。界面保存的设置优先。

## ComfyUI

1. 自行运行 ComfyUI，并准备所需模型、LoRA 和节点。
2. 从 ComfyUI 导出 **API 格式**工作流。节点对象应包含 `class_type` 和 `inputs`，不支持直接提交界面格式的 `nodes` 数组。
3. 可在工作流字符串中使用 `{{input_image}}`、`{{positive_prompt}}`、`{{negative_prompt}}`。原图占位符出现时，系统先上传所选原图，再替换实际服务文件名。节点 ID、数值、种子与模型名称沿用你的工作流。
4. 在风格库保存工作流，作品中选择配方，再用首张已选照片试运行。当前按单张测试，尚无批量生成或取消功能。
5. 输出作为新素材保存，默认不勾选，不覆盖原片；记录父图片、配方、实际工作流和 ComfyUI prompt ID。

## 存储

`data/workspace.sqlite3` 保存项目、配方、任务；`data/assets/` 保存按内容哈希命名的原片和预览；`data/settings.json` 保存本机连接设置（权限 0600）。API 不返回凭证。备份整个 `data/` 即可保存工作空间。可通过 `PHOTOMAKER_DATA_DIR` 指定另一位置。

本版仅绑定 `127.0.0.1`，用于个人本机工作；没有多人权限与云部署机制。小红书选择器与标题计数函数抽取自 Easel 的固定提交，详见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。其余工作台代码为本项目实现。

## 小红书连接（实验版）

浏览器辅助不是官方授权接口。[创作服务平台协议](https://agree.xiaohongshu.com/h5/terms/ZXXY20260422001/-1) 第 7.2(3) 条限制未经授权的第三方软件登录或使用平台，第 6.1 条列明违规处理措施。无法承诺不触发验证、限流或账号限制；手动点击发布不能消除这项风险。也可使用导出包，自行在普通浏览器官方页面发布。

依赖单独安装到项目虚拟环境，不更改系统 Python：

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-xhs.txt
# macOS 已安装 Google Chrome 时直接使用 Chrome；其他环境需要：
.venv/bin/python -m playwright install chromium
.venv/bin/python app.py
```

1. “连接设置 → 小红书 → 打开登录窗口”：阅读提示后在官方窗口登录，手机号、验证码只在官方网页输入。
2. 保持窗口打开。连接器进入官方图文编辑页，等待异步加载的图片上传控件后确认连接，不把存在 Cookie 当作已登录。上传只使用声明接受图片的文件控件，避免误用默认视频输入框。
3. 作品的“发布归档 → 准备小红书草稿”，确认上传后填写当前已选原图和标题、正文；不上传创作备注。1–18 张图、标题 20 全角字、正文 1000 UTF-16 字符是本版保守上限，超限拒绝而非截断。
4. 在官网检查图片顺序、文案、话题关联、AI 标注并亲自点击发布。这里的“草稿”是网页编辑器待提交内容，未确认云端保存；关闭前请自行保存或完成提交。
5. 官网出现明确且可见的「发布成功」或「笔记发布成功」提示时，连接状态更新为「已确认发布」，但审核与公开可见性以官网为准。页面跳转、上传完成或保存草稿不算发布成功。
6. 如果发布成功提示已经消失，点击「我已在官网发布 · 登记」，核对当前本地版本与官网内容一致后保存档案。手动确认记录与官网成功提示分开标注；仅在本地档案保存成功后更新状态，不会再次上传或发布。档案持久保存，浏览器连接状态本身在服务重启后复位。准备另一篇时关闭并重新连接。

验证码或异常会暂停/中断自动准备；没有重试提交、账号轮换或验证码绕过。会话在 `data/browser-profiles/xiaohongshu/`（目录权限 0700），属于敏感本机资料，不进入导出 ZIP。关闭连接保留会话，不等于退出账号；可在官方窗口手动退出。服务重启后连接状态复位，下次打开重新检测。

已验证真实登录会话和官方图文上传控件（接受 .jpg/.jpeg/.png/.webp）。尚未完成真实图片上传、文案填写或发布验收。失败时状态显示具体步骤（打开编辑页、选择图文模式、上传第几张图片、填写或核对文案），不自动重试。连接状态的 diagnostics 仅返回控件结构，不含账号、正文或 Cookie。平台网页选择器发生变化时需要更新。

## 验证

```sh
python3 -m unittest discover -s tests -v
```

测试使用独立临时数据目录及本机模拟模型/ComfyUI，覆盖持久化、去重、版本恢复、导出、结构化模型响应验证、编辑冲突和 ComfyUI 输出来源。真实上游连接需使用你自己的服务验证。

可选浏览器集成测试需要 Node.js、Playwright 与 Chrome，先启动隔离实例：

```sh
python3 app.py --port 4318 --data-dir /tmp/photomaker-browser.local
node tests/browser.cjs
```

浏览器脚本只允许连接数据目录含 `photomaker-browser.` 的测试实例，会收纳该实例已有测试项目。可使用 `PHOTOMAKER_TEST_URL`、`CHROME_PATH` 配置测试地址与 Chrome 路径；Playwright 需可被 Node.js 找到。桌面、手机截图与测试发布包保存在 `test-results/`。
